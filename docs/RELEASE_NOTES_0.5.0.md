# ClipVault 0.5.0 Preview 1

本版本为经常在 ChatGPT 和浏览器中输入长文字的用户增加本地草稿保护，遇到网页刷新、网络异常或输入框被清空时，可以查找之前保存的版本。

- 新增 Chromium 浏览器扩展：默认保存 ChatGPT 网页输入的草稿，其他网站需手动允许；中文输入法确认后的文字、英文和粘贴内容均可保存。
- 扩展独立本地备份，即使 ClipVault 没运行也能按日期查看、搜索、复制。较长内容被删除或明显缩短时尽量保留旧版本。
- 桌面端新增“浏览器草稿”页面，可选择开启仅限本机的配对同步，按日期浏览、搜索和复制。断开后浏览器副本仍保留，恢复连接会重试。
- 延续已有的手动创建内容、列表与宫格、批量复制以及关闭面板后再调整顺序。

## 安装和使用

下载 `ClipVault-0.5.0-preview.1-windows-x64.exe` 和 `ClipVault-0.5.0-preview.1-browser-extension.zip`。解压扩展，在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 打开开发者模式并加载解压后的文件夹；详细步骤和配对方式见 [浏览器草稿说明](https://github.com/fqxxzyw/ClipVault/blob/main/docs/BROWSER_DRAFTS.md)。完整目录版及开源许可、SHA-256 校验文件也随 Release 提供。

## 隐私与限制

草稿保存在本机且未加密；密码、验证码、支付字段采用尽力排除，无法保证识别所有敏感信息。扩展默认只在 ChatGPT 站点记录；可暂停并单独允许其他网站。浏览器副本最多 500 条、30 天，卸载扩展会删除其副本；桌面副本独立保留。扩展不支持隐身窗口、iframe、浏览器内部页面或独立桌面程序，特殊编辑器可能不兼容。崩溃可能丢失最后几秒或尚未确认的输入。真实 Windows 交互桌面和各个网站的兼容性仍需实际验证。
