# ClipVault 0.2.0 Preview 1

本地智能剪贴板工作台更新。

- 中英文/系统语言切换，保存即生效，保留搜索和选中内容。
- Markdown 本地渲染/原文视图；专属 Markdown / 纯文本复制选项。
- 仅内容小窗，单击复制、键盘操作、托盘及快捷键目标设置。
- Code / TXT / Markdown、图片与文件分类；本地日期范围筛选。
- 离线 Emoji 面板，以及复制、字符、行数、常见表情、图片、文件、ClipVault 复用统计。
- 本地 PNG 图片存储、缩略图、预览及恢复复制；文件路径记录与图标。
- 200ms 可中断过渡、清晰键盘焦点；减少动效并读取 Windows 动画偏好。
- v3 数据库迁移保留既有收藏和置顶；删除同步清理关联图片。

统计从本版启用后开始。粘贴事件不由系统剪贴板提供，本版不记录键盘，不编造粘贴次数。图片无敏感内容识别，复制保密内容前请暂停。

本机验证：123 passed / 3 skipped，Ruff 与源码隔离启动检查通过。Windows 构建结果与下载位置更新在 README 和 VALIDATION；Windows 10/11 真实桌面验收仍未完成，因此为预览版。

完整解压 onedir ZIP，再运行 ClipVault.exe；保留 `_internal`、`licenses` 和通知文件。Actions 下载需 GitHub 登录，产物有保留期限。
