# ClipVault 0.4.0 Preview 1

本次更新统一 Windows 11 风格的浅色和深色界面，保留 Windows 原生标题栏、窗口缩放与系统圆角，去掉主界面顶部额外描边。

- 从历史记录复制后，当前可见的主窗口和小窗不会立即因本次复制而调整顺序。所有面板收起后再按最近复用时间排序；使用次数仍立即计入统计。
- 主窗口和小窗都可切换列表与宫格。进入多选后逐项点击，再点击“复制所选”；主窗口的“全选已加载”只选择已经加载出来的记录。
- 多段文本按界面显示顺序复制，相邻记录之间插入空行；启用原有文本清理设置时仍遵循该设置。
- 多张图片保持各自尺寸与像素，提供独立的 PNG 文件列表及富文本；图文混合提供富文本和纯文本回退。目标程序决定接受哪一种格式；普通文本框无法显示图片，部分聊天或编辑软件不支持粘贴多张图片或内嵌图片。
- 一次最多选择 100 条，图片 PNG 合计不超过 40 MiB。多图文件粘贴会在应用数据目录 `clipboard-cache` 生成临时 PNG，保留至少 7 天，并在下次多图文件复制时清理过期批次；退出应用后仍能继续粘贴。
- 依赖暂时限定为 PySide6 6.8–6.11：验证中发现 6.12 与 Linux / Python 3.11 组合在进程退出时可能发生引用计数崩溃。

## 下载

- `ClipVault-0.4.0-preview.1-windows-x64.exe`：单文件程序，下载后运行；同时提供单独的许可证压缩包。
- `ClipVault-0.4.0-preview.1-windows-x64.zip`：完整目录版，完整解压后运行其中的 `ClipVault.exe`，保留 `_internal` 和许可证目录。
- `ClipVault-0.4.0-preview.1-licenses.zip`：单文件程序对应的许可证与第三方声明。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

这些附件由 Windows CI 构建，并在隔离配置和 Qt offscreen 环境进行启动/退出检查；Linux 和 Windows 自动化测试通过后才发布。**真实 Windows 10/11 登录桌面的原生剪贴板、多图粘贴、标题栏及 DPI 行为仍需实机验收**。文件未进行代码签名。
