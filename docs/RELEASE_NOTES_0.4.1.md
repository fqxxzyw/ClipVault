# ClipVault 0.4.1 Preview 1

## 手动创建常用内容

- 主窗口点击“新建内容”，或点击小窗顶部的加号；输入后选择“保存”或“保存并复制”。
- 默认加入收藏，避免被自动清理；可取消勾选，作为普通历史记录保存。即使暂停了剪贴板监听，也可以主动创建内容。
- 保存时保留输入文本；复制时遵循原有“自动清理复制文本”设置。相同内容会去重，不会取消已有收藏。
- 保存失败时输入内容会留在窗口中，方便检查后重试。新增清晰的勾选标记，统一深浅主题下的复选框视觉。
- 手动内容保存在本地、未加密；主动保存不会经过自动敏感内容过滤，请避免保存密码或密钥。本版不会自动记录其他应用中的输入。

## 下载

- `ClipVault-0.4.1-preview.1-windows-x64.exe`：单文件程序，下载后运行，无需安装 Python。
- `ClipVault-0.4.1-preview.1-windows-x64.zip`：完整目录版；完整解压后运行其中的 `ClipVault.exe`。
- `ClipVault-0.4.1-preview.1-licenses.zip`：许可证与第三方声明。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。

附件由 Windows CI 构建，在隔离配置和 Qt offscreen 环境下通过启动/退出检查；自动测试全部通过后才发布。真实 Windows 10/11 登录桌面的剪贴板、输入法、DPI 和交互仍需实机验收；程序未进行数字签名。
