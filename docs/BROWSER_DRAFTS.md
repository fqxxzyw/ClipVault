# 浏览器草稿保护

这个功能帮助你找回网页刷新、网络中断或误清空输入框前的文字。扩展先把草稿保存到浏览器本地；你也可以连接 ClipVault，把副本同步到软件的“浏览器草稿”页面，按日期查看。扩展和桌面程序都不会上传草稿。

## 1. 安装扩展

1. 从 [ClipVault Releases](https://github.com/fqxxzyw/ClipVault/releases) 下载 `browser-extension.zip` 和新版 ClipVault EXE。
2. 把扩展 ZIP 完整解压到一个长期保留的文件夹，确认文件夹中直接有 `manifest.json`。安装后不要移动或删除该文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，或在 Edge 地址栏输入 `edge://extensions`；开启“开发者模式”。
4. 点击“加载已解压的扩展”，选择刚才包含 `manifest.json` 的文件夹。可以在浏览器的扩展菜单中将 ClipVault 图标固定到工具栏。
5. 在 ChatGPT 网页输入一段测试文字，稍等片刻，点击扩展图标，在“历史草稿”确认内容已保存。默认允许 `chatgpt.com` 和 `chat.openai.com`。
6. 如需其他网站，在该网站打开扩展，点击“允许本站”。浏览器会提示扩展可以访问网页；只有默认或你主动允许的站点才会自动记录，可随时在扩展中暂停或停止记录本站。

扩展必须为每个浏览器、每个浏览器用户资料分别安装。当前只支持 Chrome、Edge 等 Chromium 浏览器的网页；不支持浏览器内部页面、其他应用或 ChatGPT 独立桌面程序。隐身窗口不记录。网页中的内嵌 iframe、特殊编辑器或网站更新可能导致无法读取，请先在常用网页测试。

## 2. 找回文字

点击扩展图标，在“历史草稿”里按日期浏览或搜索；展开需要的版本，点击“复制”，再回到输入框粘贴。即使 ClipVault 没有运行、网页暂时断网，浏览器中的草稿仍可查看。扩展默认保存最多 500 条、30 天并有约 5 MB 的总量限制；达到限制会优先清理较旧记录。清理在保存新草稿时执行。

输入框从长文被清空或大幅缩短时，扩展会尽量保留此前版本。它不会自动把文字插回网页，避免覆盖新内容。正常输入稍停后保存，持续输入期间定期保存；中文输入法选择候选字的过程中等文字确认后再保存。突然断电或进程崩溃可能丢失最后几秒或尚未确认的文字，无法保证恢复所有内容。

## 3. 可选：同步到 ClipVault

1. 打开 ClipVault，进入左侧“浏览器草稿”，点击“开启浏览器同步”。
2. 点击“复制配对码”。打开浏览器扩展，展开“连接 ClipVault”，粘贴配对码并点击“连接”。如浏览器询问是否允许访问本机，请允许。
3. 扩展会通过仅监听 `127.0.0.1:47963` 的本机连接同步草稿；ClipVault 关闭时，浏览器继续保存，软件再次打开后会重试。成功同步后可在 ClipVault 中按日期查看、搜索、复制和删除。
4. “停止浏览器同步”只关闭本机连接；扩展中保存的副本独立存在。要停止网页自动保存，请打开扩展关闭开关。ClipVault 主界面的“暂停”只暂停剪贴板监听，不控制扩展。

ClipVault 最多保留 2,000 条浏览器草稿，并使用设置里的“保留天数”（永不、7、30 或 90 天）自动清理。浏览器和 ClipVault 中的副本各自管理：在一边删除不会删除另一边的副本。卸载扩展会删除浏览器中该扩展的本地数据；如果要保留，请提前完成同步或复制。

## 隐私说明

草稿和配对码存储在本机，草稿未加密。同一 Windows 用户账户或可访问浏览器资料的人可能读取。扩展尽量排除密码、验证码、银行卡等字段，但网页标记不规范时可能无法识别；请避免在允许记录的网站输入密码、密钥和其他敏感信息。关闭扩展开关可停止网页记录。输入法并没有被系统级监听：扩展根据允许网站上的输入框变化保存文本，包含中文、英文、粘贴和修改。
