# Windows 真实桌面验收

本机运行环境为 Linux。远程 Windows Server 2025 CI 的 onedir 构建和隔离启动检查已通过；下表其余 Windows 10/11 真实桌面项目均为 **未执行**。

先用公开样例测试，避免包含真实密码、Token、私钥或个人数据。使用独立数据目录；测试脚本会改变真实剪贴板并尝试恢复原格式，复制未保存的内容前请先保留副本。测试过程中暂停其他 ClipVault 实例，避免样例进入日常历史。

## 原生集成测试

PowerShell，在真实 Windows 登录桌面中执行：

```powershell
$env:CLIPVAULT_DESKTOP_TESTS = "1"
$env:QT_QPA_PLATFORM = "windows"
.\.venv\Scripts\python.exe -m pytest tests/test_windows_native.py -v
Remove-Item Env:CLIPVAULT_DESKTOP_TESTS
Remove-Item Env:QT_QPA_PLATFORM
```

包含另一个进程修改系统剪贴板并触发应用监听、原生快捷键注册/冲突/释放、`WM_HOTKEY` 到 Qt 的消息传递。最后一项注入原生线程消息，**不是物理按键验证**。这些测试不在默认 CI 中执行。

## 0.2.0 新增实机检查（均未执行）

- 简体中文 / English / 跟随系统切换，重启保持，所有弹窗/托盘/统计/复制选项语言一致。
- 图片：使用公开测试图片在其他应用 Ctrl+C，缩略图、缩放预览、恢复复制、去重、暂停、关闭图片记录和重启读取；删除后图片数据同步移除。
- 文件：资源管理器复制公开样例文件，保存路径与图标；复制回的是路径文本，原文件不被读取、移动或删除。
- Markdown：标题、列表、表格、代码块；原文 / 渲染切换；Markdown / 纯文本复制，远程/本地图片不加载。
- 小窗：单击复制并隐藏、Enter/Esc、Alt+F、Alt 拖动、滚动增量加载；快捷键选小窗，多屏定位与焦点丢失行为。
- 日期：今天与自定义跨月区间，开始/结束日边界及本地时区正确。
- 统计：复制去重但次数增加、内部复用不算新复制，隐私过滤/暂停不计入，行数/常见表情、图片和文件计数可重启保留；粘贴次数保持明确不可观测。
- Windows“动画效果”关闭后无自定义过渡；设置减少动态效果立即取消进行中的过渡；长列表空闲无动画定时刷新。
- Emoji：Windows Segoe UI Emoji 呈现，鼠标/Tab/Space 复制；不同字体大小与 DPI 无布局溢出。
